# Selectively port the reference plugin

Codex Window Reset selectively ports the proven CLIProxyAPI ABI bridge, strict SSE probe parsing, quota protocol parsing, host Management API conventions, atomic persistence, tests, and release mechanics from `tapaixx/codex-health-monitor` while redesigning the scheduling boundaries and panel. The panel intentionally follows the reference integration for account discovery through `/v0/management/auth-files` and operator-triggered display refresh through `/v0/management/api-call`. Runtime scheduling, guardrails, reset single-flight, and durable idempotency remain plugin-owned. Copying the repository wholesale would preserve duplicate schedulers, global runtime registries, and script-order overrides; a clean-room rewrite would discard validated protocol behavior without a compensating benefit.
