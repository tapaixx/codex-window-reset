# Share a probe request and separate its outcomes

A Health Probe and a scheduled Preheat Request are different intents carried out by the same minimal real Codex Probe Request, which may begin a Short Window and consume ordinary quota. The plugin records Request Outcome separately from Window Outcome, so a valid model response proves account health but cannot by itself prove that a new Usage Window started; an unverified window effect is reported without retrying a successful request.
