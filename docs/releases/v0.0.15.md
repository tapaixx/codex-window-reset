# Codex Window Reset v0.0.15

## 额度刷新

- 用量返回后逐账号显示，不再等待整批账号和重置次数全部返回。最多并发处理 3 个账号。
- 单次用量请求 15 秒超时，重置次数详情 5 秒超时。详情暂不可用时保留已更新的用量，并保持重置按钮不可用；用量失败时保留旧快照并标记过期。
- 面板后台加载不再静默阻止显式额度刷新；迟到的缓存不会覆盖刚刷新的额度。历史和审计分别加载、分别显示。

## 检测历史批次

- 自动预热按日期与计划时段分组，同一轮账号在不同分钟错峰执行仍属于一批，失败补偿也归入原批次。
- 手动检测按任务分组；不同日期、时段和手动任务分别展示。无法识别批次的旧记录独立保留，不以时间接近猜测分组。
- 批次摘要分别显示账号数和操作数，展开查看各账号的执行时间及结果；刷新历史后保留展开状态。

## 验证与更新

针对额度超时、部分结果、并发和批次归并的相关单元测试 19 项通过。源码页面和真实 Go 嵌入页面各 8 项关键交互通过，真实页面另通过未保存草稿保护检查。未调用真实账号或上游服务；上游自身响应速度未作保证。根因和防复发规则保存在 `docs/verification.md`。

更新对应架构的插件并重新加载，页面顶部应显示 v0.0.15。无需删除配置或历史数据。
