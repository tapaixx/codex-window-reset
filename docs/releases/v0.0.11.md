# Codex Window Reset v0.0.11

## 本次更新

- 时间轴聚焦工作与预热时段，上下班边界、刻度、预热点及覆盖色块使用统一坐标；补齐边缘刻度。
- 明确 A/B 策略含义，零收益显示“当前参数下无额外收益”，不再用绿色正向增益误导。
- 增加“刷新全部额度”：先重新发现宿主凭证，再刷新已启用账号，支持宿主重新启用的凭证；自动预热账户集合不随发现结果自动扩张。
- 将原刷新按钮明确为“刷新已选额度”；刷新结果分别统计成功、失败和跳过，失败快照标记过期，成功结果不会被其他账号的失败丢弃。
- 配置错误显示到具体字段并定位焦点；保留合法的 0 阈值。刷新面板及保存响应不再覆盖未保存的新修改。
- 修复手机端单账户选择与按钮挤压，统一整页及弹窗深色主题，补齐键盘焦点、标签、弹窗标题和减少动态效果支持。

## 验证与更新

源码及 Go 实际内嵌单页均通过 62 项 Node/Chromium 回归；覆盖手机、桌面、深色主题、部分失败、重新启用凭证和空账户集合。发布流水线还会执行原生 amd64/arm64、Go race/vet 和发布包布局校验。

支持 Linux amd64 / arm64。使用插件商店更新，或安装对应架构文件后重载插件、重新打开页面；顶部应显示 **v0.0.11**。无需清空配置，不新增宿主登录或凭据存储。

测试使用虚拟宿主接口，没有在用户真实账号上执行额度消费、预热或重置。
