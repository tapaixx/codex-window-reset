# Codex Window Reset v0.0.10

## 本次更新

- 参照 Codex Health Monitor 重做参数维护与模拟器布局：参数侧栏、四项指标、A/B 策略卡、预热时段概览和工作日时间轴。
- 修复 A/B 轨道重复使用同一组分段，以及预热点被错误拉长到午夜的问题；轨道分段与服务端覆盖指标使用同一组计算区间。
- 增加时间轴图例、分段明细、键盘可访问的预热详情、小屏横向滚动及模拟器暗色样式。
- 修复页面版本号写死为 v0.0.8 的问题，改为读取发布构建版本。
- 保留空账户集合配置：可以保存并启用配置，集合为空不会触发自动请求；模拟预览不消耗真实配额。
- CI / Release 增加实际 Go 嵌入单页的浏览器检查，验证版本号、非空时间轴及无二次静态资源请求。

## 安装与更新

支持 Linux `amd64` 和 `arm64`。插件商店使用对应架构 ZIP 和 `checksums.txt`，手动安装可使用对应 `.so`。

更新后按 CLIProxyAPI 的流程重载插件，再重新打开面板。页面顶部应显示 **v0.0.10**；如果仍显示 v0.0.8，说明宿主仍在提供旧插件页面，需要检查加载的插件文件及重载结果。

本次不更改配置结构或凭据归属，无需清空配置与账户集合。预热、检测和额度重置仍使用原有服务端逻辑；UI 参考布局不代表采用参考项目的模拟算法。
