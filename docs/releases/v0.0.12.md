# Codex Window Reset v0.0.12

## 本次修复

- 修复模拟器策略 B 忽略实际预热时间、可用区间与策略 A 相似的问题。
- A 从首次工作开始、B 从上班前最早有效预热开始，按配置的窗口周期推演；不再在每段工作开始时错误恢复预算。
- 同一窗口内的可用时长跨午休保留：午休不消耗，也不会额外重置额度。统计指标与时间轴共用同一组可用区间。
- 明确单账户模拟假设：多账户错峰不会叠加可用预算，没有提前预热则 B 与 A 相同；后续预热请求不代表强制重置窗口。

示例：工作 09:00–12:00、13:30–19:00，窗口 5 小时、每窗口可用 60 分钟，06:30 预热。A 可用 2 小时，B 可用 3 小时，净收益 1 小时；B 的 11:30–12:00、13:30–14:00 和 16:30–17:30 正确显示绿色可用区间。

## 验证与更新

已逐段对照参考项目的周期模拟结果；Go 全量测试、race/vet，以及源码和 Go 实际内嵌页面的 63 项 Node/Chromium 回归通过，覆盖桌面明暗主题和移动端。发布流水线另执行原生 amd64/arm64 验证与发布包校验。

支持 Linux amd64 / arm64。更新并重载插件、重新打开页面后，顶部应显示 **v0.0.12**。无需清空配置。

本次只修正模拟器，不改变实际调度、预热和额度操作；模拟结果不是上游真实额度保证。验证没有使用真实账户或消耗额度。
