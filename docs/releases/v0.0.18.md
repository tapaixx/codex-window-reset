# Codex Window Reset v0.0.18

## 修复自动预热阻塞

- 自动预热执行前后的额度刷新现在有 15 秒独立超时。上游额度接口卡住时，记录额度刷新失败并继续按 fail-open 规则执行预热探测，不会一直停在“未开始预热”。
- 额度刷新属于只读诊断，刷新全部额度和单账号刷新都包含停用账号；停用账号仍不会进入手动检测、重置或自动预热操作。
- 模拟器不再为每次草稿输入重复发现宿主账号，且过期的并发模拟响应不会覆盖最新结果。

根因和回归：后台调度原先复用了无截止时间的 scheduler context 调用额度接口；前台刷新虽有超时，自动预热没有。新增阻塞额度接口测试，验证超时后真实预热请求仍会启动。
